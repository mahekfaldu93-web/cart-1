# 🛍️ ProStore - Product Management System

ProStore is a simple and responsive **Product Management System** built using **HTML, CSS, and JavaScript**.

This project allows users to add, edit, delete, search, filter, and sort products. Product data is stored in the browser's **LocalStorage**, so the data remains available even after refreshing the page.

---

## 📌 Project Overview

ProStore is designed as a product dashboard where users can manage different types of products such as:

- 📱 Mobile
- 💻 Laptop
- 📷 Camera
- ⌚ Watch
- 👟 Shoes
- 👕 Clothes
- 🔊 Speaker
- 🎧 Headphones
- 🎵 Buds
- 🖱️ Mouse
- 🔋 Power Bank

The application uses JavaScript to dynamically display and manage products.

---

## 🚀 Features

### ➕ Add Product

Users can add a new product by entering:

- Product Name
- Price
- Image URL
- Category

The new product is automatically stored in LocalStorage.

---

### ✏️ Edit Product

Users can edit an existing product.

Clicking the **Edit** button loads the product information into the form.

The user can then update:

- Product Name
- Price
- Image
- Category

After updating, the product is saved again in LocalStorage.

---

### 🗑️ Delete Product

Users can delete any product using the **Delete** button.

Before deleting, a confirmation message is displayed.

---
